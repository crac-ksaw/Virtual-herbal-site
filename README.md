# 🌿 Green Wisdom - Plant Benefits Blog

A beautiful, modern website dedicated to exploring the wonders of plants, their benefits, and their impact on our lives and environment.

## ✨ Features

### 🎨 Modern Design
- **Responsive Layout**: Works perfectly on desktop, tablet, and mobile devices
- **Glass-morphism Effects**: Beautiful semi-transparent elements with backdrop blur
- **Smooth Animations**: Scroll-triggered animations and hover effects
- **Custom Scrollbar**: Hidden scrollbar for a clean, modern look
- **Gradient Backgrounds**: Beautiful green gradients that match the nature theme

### 📱 Multi-Page Structure
- **Home Page** (`index.html`): Landing page with hero section, featured content, and call-to-action
- **Articles Page** (`articles.html`): In-depth plant articles with featured content and search functionality
- **Categories Page** (`categories.html`): Plant categories with interactive cards and statistics
- **Benefits Page** (`benefits.html`): Comprehensive guide to plant benefits with detailed information
- **Newsletter Page** (`newsletter.html`): Newsletter signup and subscription management

### 🚀 Interactive Features
- **Hero Fade-out**: Hero sections fade as users scroll down
- **Parallax Effects**: Content appears to come from above when scrolling
- **Animated Counters**: Statistics animate when scrolled into view
- **Search Functionality**: Real-time search through categories and articles
- **Hover Effects**: Cards lift and transform on hover
- **Scroll-triggered Animations**: Elements fade in as they enter the viewport

### 🎯 User Experience
- **Smooth Navigation**: Seamless transitions between pages
- **Loading Animations**: Engaging loading screens and transitions
- **Accessibility**: Focus styles and reduced motion support
- **Cross-browser Compatibility**: Works on Chrome, Safari, Firefox, and Edge

## 🎨 Design System

### Color Palette
- **Primary Green**: `#2d5f3f` - Main brand color
- **Light Green**: `#4a7c59` - Secondary color
- **Accent Green**: `#7fb069` - Highlight color
- **Cream**: `#f4f3e7` - Background color
- **Earth Brown**: `#8b4513` - Text color

### Typography
- **Primary Font**: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif
- **Serif Font**: Georgia, 'Times New Roman', serif (for headings)

### Components
- **Cards**: Rounded corners, subtle shadows, hover effects
- **Buttons**: Gradient backgrounds, rounded corners, hover animations
- **Navigation**: Fixed header with backdrop blur
- **Hero Sections**: Full-screen with gradient backgrounds

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Safari, Firefox, Edge)
- No additional dependencies required

### Installation
1. Clone or download the project files
2. Open `index.html` in your web browser
3. Navigate through the different pages using the navigation menu

### Local Development
1. Set up a local web server (optional but recommended)
2. Open the project folder in your code editor
3. Make changes to HTML, CSS, or JavaScript files
4. Refresh your browser to see changes

## 📱 Responsive Design

The website is fully responsive and optimized for:
- **Desktop**: 1200px+ (full layout with all features)
- **Tablet**: 768px - 1199px (adjusted grid layouts)
- **Mobile**: < 768px (stacked layouts, hidden navigation)

## 🎭 Animations & Effects

### Scroll Effects
- **Hero Fade-out**: Hero sections become transparent as you scroll
- **Parallax**: Content moves at different speeds for depth
- **Fade-in**: Elements appear as they enter the viewport
- **Counter Animation**: Numbers count up when visible

### Hover Effects
- **Card Lift**: Cards move up and scale on hover
- **Button Transform**: Buttons lift and show shadows
- **Navigation Highlight**: Active states and hover colors

### Loading Effects
- **Page Transitions**: Smooth loading between pages
- **Element Animations**: Staggered fade-in effects
- **Floating Elements**: Gentle floating animations

## 🔧 Customization

### Adding New Pages
1. Create a new HTML file
2. Copy the header structure from existing pages
3. Update navigation links
4. Add your content with appropriate CSS classes

### Modifying Styles
- Edit `styles.css` for global changes
- Use inline styles in HTML files for page-specific styling
- CSS variables are defined in `:root` for easy color changes

### Adding Content
- **Articles**: Add new article cards in `articles.html`
- **Categories**: Add new category cards in `categories.html`
- **Benefits**: Add new benefit items in `benefits.html`
